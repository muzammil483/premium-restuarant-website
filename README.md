# premium-restuarant-website
A modern, responsive and premium restaurant website built with HTML, CSS and JavaScript, featuring an elegant design and user-friendly experience.
Restaurant Website

A modern and responsive restaurant website built using HTML, CSS, and JavaScript.

I created this project to build a clean and attractive website for a restaurant, with a focus on good design, easy navigation, and a smooth user experience.

Features

- Clean and modern design
- Responsive layout for mobile, tablet, and desktop
- Attractive homepage
- Restaurant menu section
- Food images and gallery
- About section
- Contact section
- Interactive elements using JavaScript
- Smooth navigation

Built With

- HTML5
- CSS3
- JavaScript

Getting Started

To run this project on your computer:

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open the "index.html" file in your browser.

What I Learned

While working on this project, I improved my understanding of HTML, CSS, responsive layouts, and JavaScript. I also got more practice organizing project files and turning a design idea into a working website.

Future Improvements
